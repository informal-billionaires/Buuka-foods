# Bukka Foods — Web App (Scaffold)

This repository is a Next.js + Tailwind CSS scaffold for Bukka Foods, a Nigerian food-delivery web app.

What's included in this scaffold:
- Next.js app structure (pages/)
- Tailwind CSS configuration with Bukka Foods brand tokens (colors, fonts)
- Global styles (dark, black-first UI)
- Basic design-system components: Button
- Landing page hero with brand styling
